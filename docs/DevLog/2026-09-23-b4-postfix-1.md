# 2026-09-23 批④后修（用户反馈轮）：脚本域跨局残留 + 资产网格 HiDPI 裁剪

批④收口提交后用户实测报五项（两项缺陷 + 三项方向问询）。缺陷当轮全修，方向
问询登记 M6（08 §M6 补记）。

- **BUG-A：Stop→Play 后环绕刃每局递增（+2/局）**。根因不在模板：`Behaviours.Slots`
  是 C# 静态实例表，ExitPlay 弃 playWorld 时**无人 Detach**（Detach 只挂单实体
  Destroy 命令路径，整世界弃置不经过）；新 playWorld 场景快照确定性装载 →
  **实体 id 与上局相同** → EnterPlay 重 Attach = 同实体双实例双 tick（PlayerBehaviour
  ×2，各维护 `_blades` 各补 2 刃；`Events.Subscribe` 构造器订阅同理跨局累积——
  击杀宝石也会翻倍）。Unity 心智差：Enter Play 默认换域重置静态，我们 Play↔Edit
  不换域（热重载连续性），"局"边界就必须显式清。修法 = **`lemon_play_reset`**
  Entry 导出（`Behaviours.ClearInstances()` 硬清实例/热重载包 + `Events.Reset()`
  清订阅/待发/计数；类型注册表保留——同域未换装，免重 Configure；OnDestroy 不调，
  实体已随旧 World 销毁句柄悬空，与 LoadScript 的 Reset 同口径）；
  `ScriptHost::ResetPlayDomain()`（启动期解析，旧 Entry 可缺席 = no-op）挂
  `EnterPlay`（ResetScriptTime 之后、装配新实例之前）。**bench/回放不经此路径 =
  金档零扰动**（m5b2-script replay 仍 mismatches=0 机械复证）。回归测试
  `TestPlayDomainReset`（+8 checks → **1485**）：同实体双 Attach 复现双实例
  （Custom 801 ×2）→ 复位清零 → 重挂单实例（700 恰 +1）。
- **BUG-B：AssetBrowser 素材多时末列被裁（无横向滚动可达）**。根因：网格列数按
  硬码 `kCell=92` 换列，而主题度量随 displayScale 缩放（FramePadding.x =
  ItemSpacing.x = 8k → 实测节距 72+24k，k≥1 时 > 92）→ 列数偏多，每行末列
  溢出右缘；子窗口只保留竖向滚动条（AlwaysVerticalScrollbar），溢出部分既不
  换行也不可滚 = 直接不可见。修法 = **按实测节距换列**（`(avail+spacing)/(cellW+
  spacing)`）+ 文件名/文件夹名 `PushTextWrapPos` 钉到按钮宽（TextWrapped 相对
  窗口右缘会让行中单元格宽随位置漂移，节距公式失准）——单元格宽确定后公式精确
  成立，任意宽度下面板自适应换列、竖向滚动承接任意数量。
