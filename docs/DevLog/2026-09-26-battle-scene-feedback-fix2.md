# 2026-09-26 · Battle 场手测反馈二——飞剑贴图认领 + 布阵几何改浅纵深

用户手测反馈（截图实证）：飞剑"还是不会飞"（表现为满屏青白圆点）、"屏幕中间
都没有角色"。对照 AllyBehaviour 逐行核对 + 截图分析，两因：

## ① 飞剑圆点 = 认领漏了贴图交换

`FlySword.prefab` 自带**兜底贴图**（拖尾光点源 blade.png），AllyBehaviour 认领后
**一次性换指向性飞剑贴图**（`UpdateSwords` 内 `sr.SpriteId = _swordSprite`）——
RedVsBlue 的认领链只做了偏转/追踪/朝向，漏了这一步 → 760 把剑以光点形态飞行
（圆点旋转不可辨 = "不会飞"观感；穿透/寿命销毁路径本就在，"不消失"亦为同因
观感）。**修**：认领处一次性 `SpriteId = flysword.png` + Scale 1.2 + Rot 出膛向。

## ② 中间空 = 深纵深立阵大半在屏外 + 飞剑停进过远

原布阵 4000/边 × 18 间距 = 每边纵深 2000px，而默认视野半宽 ~640——**约 2800/边
站在屏外立阵**（Chase 视距 320 内无敌 = 永不前进的白占负载）；飞剑型又停在距敌
220 → 中线形成 ~440px"光点无人带"，绞肉线被光点云盖住。**修**（布阵几何以
"视野装得下"为准）：首波 1500/边 × 13 间距 × 48 行 ≈ 400px 深（全在视野内）、
前沿距中 60/边、飞剑停进 220→150（贴本方英雄后排齐射，收窄中带）、补充节拍
2s/400 → 1s/300。总兵力口径（10000/边）不变——余量转为持续兵流。
