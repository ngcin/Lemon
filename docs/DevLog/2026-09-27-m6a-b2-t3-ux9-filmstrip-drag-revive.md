# 2026-09-27 · M6a 批② T3-UX9：胶片带三修（列宽/拖拽复活/文案）+ 注入路由排障

## 事件

用户截图三报（帧列表右侧大片空白但换行 / 拖拽重排无效 / 拖图入格没法拖 +
"左右箭头多选"误会）→ 讨论定方案 A（修而非砍）实施。
[批文件](../Plans/M6a/2026-09-27-b2-t3-ux9-filmstrip-drag-revive.md)。

要点：

- **拖拽三通道自出生即死**：帧格 = 裸 `ImGui::Image`（无 ID）——无 ID 项做
  拖源需 `SourceAllowNullID`（没带 → 永假），拖靶只认图矩形。修 =
  `DrawCellImage` 加 `idStr` 参数 → `InvisibleButton` + drawlist 直贴；胶片带
  格/预览接入，浏览器瓦片（ImageButton）模式对齐。
- **列宽公式**：去掉不存在的 2×FramePadding 虚耗（每格 8~16px × 列数 =
  截图里"空一格半 + 提前换行"的量级）。
- **文案歧义**：←/→ 是移选非多选；改"单击选中 · Ctrl/Shift+点击多选 · ←/→
  移动选择 …"，多选本就支持（T3-UX4 Finder 语义）。
- **注入路由排障（重要遗产）**：为拖拽写了四轮注入时序全败——注入点击在
  普通窗口被 ImGui 1.91 窗口兜底路由吃掉（悬停瞬移建立，点击路由撞
  "HoveredId 空 → 绑窗口 MoveId"）；既有注入点击链全在模态窗（路由不同）
  从未暴露此坑。真人不受影响。**结论：普通窗口交互 = 语义断言锁（帧格项
  ID 非零 = `StripCellItemForTest`，f118 + `drag(item=)` 位，阴性验证
  红→复绿），手感归真人验收。**后续给普通窗口写注入链前先读本条。
- 夹具纪律再证：`--frames 120` 时 frame 计数 0..119，链排 f120 = 死代码
  （首跑 drag(item=NO) 且无错误行 = 链没跑的特征）。断言挪 f118。
- 验证：smoke-anim `=> OK`（drag(item=YES)）+ full 14/14 + 阴性验证过。
