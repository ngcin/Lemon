# 路线图重排：Windows/出包优先，M6d+③e → 新增档位 M9

- **日期**：2026-09-30（用户三拍板，讨论基座 = 两份评审报告 + 16 条复核结论）
- **决策**：

1. **M6d Tilemap+TD → 新增档位 M9**（路线图原止于 M8），**M6b ③e 图鉴随迁**——图鉴是游戏玩法内容，与 TD 模板同批消费更贴；M6b 以 ③d-2 + 真人验收收官。
2. **M6c 音频先于 M7 出包主体**（对调原建议的"最小面先出包"排序）——理由：无声音的二进制不算"完整运行"；.baked 音频资产类型随 M6c 定形，M7 packager 一次做全类型（与路线图 M7 原依赖方向一致）。
3. **M7 拆两段**：M7a 独立运行时+最简出包先行（`Engine/Assets` 运行时资产层 + GameEntry/lemon-game + 目录拷贝式 packager，评审建议书 R1 最小面）；Steam/安装器/云档等发行侧后置 M7b，真包后再议。

- **动因**：评审总判断——内核纪律的边际收益已过顶，"能跑起来的独立 demo + Windows + 可出包二进制"边际收益最高；M7 的真实前置不是打包脚本而是整层运行时资产能力（评审 §5.4：运行时零 PNG 解码、无 GameEntry、资产库住在 lemon-editor-core）。
- **新顺序**：第 0 批清障（同日完成，[批⓪](../Plans/M7/2026-09-30-b0-gate-c-and-defect-batch1.md)）→ **M6c 音频 → M7a 独立运行时+最简出包（穿插缺陷第二批）→ M7b 发行侧 → M8 光照打磨 → M9 Tilemap+TD+图鉴**。
- **顺序约束登记**：D4（UI 事件绕域线程）保持"任何模拟/渲染分线程之前必须修"约束——本计划不碰分线程，暂安全；D5 上提至 M7a 批（独立运行时的 Prefab 生成路径定形时一并加护栏，复核新发现：模板 UpdateBlades 已踩失效窗口）。
- **落账**：[08 路线图](../EngineDesign/08-Development-Roadmap.md)（文首注记 + 总览表 + §2 M6b/M6c/M7/M9 节 + §7 映射）、[M6b.md](../Plans/M6b/M6b.md)（③e 迁出行）、[M7.md](../Plans/M7/M7.md)（新枢纽页）、AGENTS.md 阶段行、README win 承诺兑现。
