# 2026-10-01 M6c 听感验收驱动热修：母带软限幅 + 同 clip 并发上限

## 事件

用户真人听感验收批①b/批② 时报：**kill.wav 多个一起发感觉破音**。定位非 miniaudio/设备层、也非整型回卷（总线 f32 + 求和后硬钳），是混音器两个设计缺口叠加：

1. **母带总线只有硬钳 ±1.0**：多声部线性求和超顶后峰值被斩平成近似方波（听觉上的"破音"）。实测击杀音 `.baked` 峰值 −6.48 dBFS、脚本 0.6 音量播 → 单声部峰值贡献 0.28，同帧 4 杀 = 1.14、6 杀 = 1.71，全部过顶；同帧触发的同一 clip 采样完全对齐 = 最坏相干叠加。
2. **同 clip 重触发无限叠**：AudioChannel/engine 无 per-clip 并发管理，64 池来一个开一个——幸存者类 AoE 一炸多杀必然叠爆。

非回归：批①b 之前即此行为，流式没动求和路径。

## 落地（业界标准两件套）

- **母带软限幅**（`MixVoices` 末端，硬钳替换）：膝点 0.8——膝下位零增益位精确透传（常态路径无超越函数）；过载段 `0.8 + 0.2·tanh((x−0.8)/0.2)` 渐近压回，膝点 C1 连续无斜率跳变；**L/R 共用同帧峰值增益**（联动限幅——独立限幅过载时拉偏声像）。
- **同 clip 并发上限** `kMaxVoicesPerClip = 4`（`PlayLocked`，业界 per-sound voice limit 同构）：超限**偷最老**（`startSeq` 最小）；释放复用 D4 包络 5ms 淡出到零（硬停切波前有咔哒）+ `stopAtFadeEnd` 终结——**释放中不计活跃**，连发脉冲下"活"声部恒 ≤ 4。BGM 交叉淡出的旧曲带 `stopAtFadeEnd` 天然不计活跃，同 clip 重触发 BGM 不受干扰。

## 实测

- 引擎单测 **34023 checks**（34008 → +15）：`TestAudioMasterLimiter`（膝下位透传 ±1e-6 / 中度过载锁曲线本体 / 深过载严格 <1.0 且单调不过压）+ `TestAudioVoiceCapSteal`（上限内共存 / 超限偷最老 5ms 释放窗 / 同 tick 20 连发活跃恒 = 4 / 跨 clip 不连坐）。**一次全绿**。
- 既有 `TestAudioBench100Sfx` 断言语义更新：100 同 clip 连发后活跃 = `kMaxVoicesPerClip`（原 = 池满 64）——释放中声部占槽，65+ 发仍穿过池满偷取路径，两级偷取都被走到（计时断言 0.5ms 不变，0.021ms）。
- ctest 3/3；`--smoke-audio` OK。
- svr-test `--smoke --play --frames 240`：`进 Play 音频装载：8 成功（流式 2），全部就绪` 零欠载。**注意**：`script-spawn: playAlive=6 seeded=6 => FAIL` 为**用户 WIP 层既有问题非本修回归**——stash 本修后在同一 HEAD 基线复现同样 FAIL，真因 = `Play 装配：脚本类型未注册（跳过）'SpawnerBehaviour'`（另有两条 prefab 低 32 位 guid 碰撞告警；9/30 的 Player01/player02 WIP 动画资产在场）。
- 既有测试幅值全在膝下位（批①b 流式字节精确断言单声部 0.216、双声部 0.43），限幅器零影响。

## 发现

1. 硬钳破音与回卷爆音听感可分：f32 总线 + 钳位排除了整型回卷，破音全部来自真实削波——曲线软化即根治。
2. 偷声部必须带释放：硬停等效在波前 `Stop()`，切点即咔哒；复用既有 D4 包络 5ms 释放是零新机制的免咔哒解。
3. per-clip 上限与池满偷取两级天然兼容：释放中声部占槽（不偷活口），池满路径照常兜底。
