# 修复：资源浏览器根视图出现无名且点不动的文件夹（Directories 哨兵泄漏）

- 日期:2026-10-13（用户走查实报；b876469 重启后的新发现，与前五轮缩略图
  修复无关的独立缺陷）
- 性质:用户报障修复，非批次项。引擎内核零改动（AssetBrowserPanel.cpp 单行）。

## 1. 实报（用户原话口径）

assets 目录的第一个文件夹没有名字，就一个文件夹图片，这个是干嘛的，也不
能点击。

## 2. 根因

`AssetDatabase::Directories()`（AssetDatabase.cpp:90）**故意以空串 "" 打头**
——那是"逐级向上收集父目录"循环的终止哨兵（项目根），从来不是可导航目录。
浏览器文件夹单元格循环没滤它：根视图下 "" 通过"根级目录"判定
（`d != "Assets"` 且不含 `/`）→ 画出无名文件夹；点击 `currentDir_ = ""`
本就是根语义 → 导航无变化，表现为"点不动"。

## 3. 修法

循环开头 `if (d.empty()) continue;`（哨兵根条目滤除；向上导航本就归面包屑
"Assets" 链接管）。
