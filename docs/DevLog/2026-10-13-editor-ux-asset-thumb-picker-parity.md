# 修复：资源浏览器缩略图照选择图片对话框同款实现（五轮定论：整幅等比居中卡片）

- 日期:2026-10-13（用户实测第五轮；079bd9b"整幅铺满+帧零截取"被否）
- 性质:用户报障追修，非批次项。引擎内核零改动（AssetBrowserPanel.cpp 单文件）。

## 1. 实报（用户原话口径）

别拉伸或者截取！选择图片对话框里面的序列帧图片也没有截取，那已经是很完美
的显示了，照着选择图片对话框实现。现在 assets 里面又是截取又是拉伸，看着
特别别扭。

## 2. 根因

四轮里我把"占满格子"理解成"图要铺满格子"，先后做了整页拉伸/帧零截取——
都改变了图本身（拉伸变形/裁掉内容）。选择器的实际做法是：**固定尺寸瓦片
卡片 + drawlist 等比居中贴整幅图**——格子视觉满（卡片恒定），图完整不裁
不拉。用户口径的"占满"指**卡片**满格，不是图铺满。

## 3. 修法（DrawItem 改为 FilePicker::DrawIconEntries 同构）

- 卡片 = 固定尺寸 `Button`（总尺寸 kThumb + 2×FramePadding，与文件夹
  ImageButton 足迹一致 → 网格统一；选中态换 Button 底色 kAccentDim）。
- 图 = `GetWindowDrawList()->AddImage` **整幅**（sprite 页 uv 0..1，
  PageInfo 取页宽高）等比 fit 双向居中贴在卡内（选择器 s=min(...) 同款
  公式）；类型图标走形状页 UV 子矩形 + tint（AddImage col 参数）。
- 未导入占位 "?" 居中 drawlist 文字。交互面零改动（hover/右键/拖拽/双击
  全绑 Button，最后一个 item 语义不变）；帧零 UV/居中偏移/标签钉 Y 等
  前四轮机制全部退役。
