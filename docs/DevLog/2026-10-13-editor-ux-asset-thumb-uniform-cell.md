# 修复：资源浏览器缩略图统一满格方格（四轮收敛 + 序列帧取第一帧）

- 日期:2026-10-13（用户实测第四轮；1c96aba 垂直居中仍不达"占满格子"口径）
- 性质:用户报障追修，非批次项。引擎内核零改动（AssetBrowserPanel.cpp 单文件）。

## 1. 实报（用户原话口径）

上下是填充了，左右没有填充；选择图片对话框怎么实现的，那里是正常的，到了
assets 下就不正常了，实现方式不一样；资源占的格子宽高还不一样。

## 2. 根因（两处口径差）

1. **实现方式不同**：FilePicker 瓦片 = 固定尺寸卡片（104×定高）+ drawlist
   贴图 → 格子恒统一；AssetBrowser = ImageButton，前三轮按图片宽高比改了
   按钮尺寸 → 竖帧（16×32→36×72）左右留空、格子宽高参差。
2. **"占满"与"拉升"的调和**：最初报障"序列帧图被拉升"的根结是**整页**
   （256×48 × 8 帧）拉伸把帧内容压扁成糊；用户要的满格不该靠整页拉伸。

## 3. 修法（DrawItem）

- **格子恒 kThumb 见方**（与选择器固定卡片同构）：ImageButton 恒 72×72，
  图整幅拉伸铺满 → 网格整齐、选中框统一、组高天然恒定（前三轮的居中偏移/
  标签钉 Y/_dummy 垫高机制全部退役删除）。
- **网格切片 sprite（序列帧图）取第一帧**：UV 取页内 (0,0)-(cw,ch) 子矩形
  （cellW/cellH 来自 .meta importer，页界校验防越界）——帧级铺满轻度变形
  但内容完整可辨（缩略图职责；Unity 对 sheet 同款）。无网格图整页铺满
  （实条图 = 色块满格；方图 = 精确满格）。
