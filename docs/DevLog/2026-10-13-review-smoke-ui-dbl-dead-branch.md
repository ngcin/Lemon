# 评审轮修：smoke-ui 驱动双击第二按下帧被诊断分支吞掉（死代码）

- 日期:2026-10-13（41b0a7c 提交后的 review 轮自查；当日编辑器 UX 走查会话）
- 性质:评审轮修复，非批次项。单文件一行（EditorAppSmoke.cpp）。

## 1. 缺陷

41b0a7c 把 smoke-ui §I 文件夹链改成双击注入（f112-115 两对按下/释放），
但 f114 本就在 else-if 链**前部的诊断帧表**里（45/55/57/65/71/97/107/109/
**114**/145/150——env 检查只在打印内部，分支匹配是无条件的）→ 新加的
`else if (frame == 114) hold(...)` 是死代码：第二次按下永不注入、双击不成
立、f116 进入断言必红。上一轮"留待下次回归验证"的驱动改动实际是坏的。

## 2. 修法

f114 移出诊断帧表（旧表值 = 单击流观察点，env 门控纯打印，去掉无功能
损失）；114/116 现归 §I 双击链专用。
