# 编辑器 SceneView 缩放 —— 滚轮量纲归一 + Godot 式档位表（用户实报修复）

- 日期：2026-10-14（用户实报："放大 64/缩小 0.05，稍微一滚就到头，很难渐进调整；Godot/Unity 很线性"）
- 方案：讨论后用户拍板 A+B 组合（A = 输入归一，B = 固定档位阶梯）
- 结论先行：**根因不在缩放公式而在滚轮量纲——macOS 连续滚动设备（触控板/妙控鼠标/自由滚轮）单帧 `io.MouseWheel` 可达 ±30 单位且带惯性，旧公式 `zoom ×= exp(wheel×0.12)` 把事件振幅直接映射成指数增长，全量程 0.05→64 仅 ≈60 个滚轮单位，轻轻一甩即打穿。修复 = SDL 侧整格量化（`wheel.integer_y`，3.2.12+ 自带残差累积）+ 每帧 ±2 格钳制 + 58 档固定倍率表（滚轮一格移一档）。**

## 1. 根因链

| 环节 | 事实 |
|---|---|
| 旧实现 | `ViewportPanels.cpp` SceneView：`cam.zoom = Clamp(zoom × exp(io.MouseWheel × 0.12), 0.05, 64)`——对格子鼠标（每格 ±1）本属渐进（12.7%/格） |
| 上游放大 | macOS 连续滚动事件为分数增量、单帧可达 ±30、松手带惯性；ImGui 1.92.9b 官方 SDL3 后端原样透传不量化 |
| 量程折算 | ln(1280)/0.12 ≈ 60 单位 = 全量程；一次中等力度甩动轻松累积 ≥60 → 直接钳在 64 或 0.05 |
| 参照 | Godot 4：一格 = 固定乘法步长（硬编码，[godot-proposals #863](https://github.com/godotengine/godot-proposals/issues/863)）；Unity：固定步长 + 相机向目标值缓动。共同点 = **缩放幅度与事件振幅解耦** |

## 2. 实现（引擎内核零改动，纯编辑器层）

- **ImGuiBackend**（`Editor/App/ImGuiBackend.cpp/.h`）：`EventThunk` 捕获 `SDL_EVENT_MOUSE_WHEEL` 的 `integer_y`（SDL 侧残差量化，逐事件 0/±1/±2 格）累积为 `s_wheelTicks`；`BeginFrame` 在 NewFrame 后发布为本帧 `frameWheelTicks_` 并清零；冒烟注入路径（`SetInputOverride` wheel=±N）同路叠加。新公开口 `WheelTicks()`。
- **ViewportPanels** SceneView：缩放输入改 `WheelTicks()`，每帧钳 ±2 格（洪峰/惯性截断，单帧最多 ≈×1.35）；倍率改档位表移步。锚点逻辑（选中对象中心/鼠标点，缩放前后屏幕位置不动）与视野外禁锚保护原样保留。
- **档位表**：35 档、端点 0.25/16（**二轮手试修订**：初版 0.05/64（58 档，端点=旧钳位界）用户反馈"仍不跟手"，量程 1280× 收窄到 64×，中间档值不变）；1× 附近 9-17%/档（主工作区精调），两端 20-25%；0.5/1/2/4/8… 像素完美倍率为表内精确值。最近档取对数空间几何中点。
- **F 聚焦**：连续计算值吸附最近档（覆盖 60% 语义在 ±半档内保持；中心对焦不受影响）。

## 3. 验证

- 构建：`cmake --build --preset mac --target lemon-editor` 零警告。
- `--smoke-drag --frames 90 --no-reopen` **三跑全绿且逐位一致**：`zoom 1.00→1.40`（3 格注入 = 1.0→1.1→1.2→1.4，×1.4 > 断言下限 ×1.25）、锚点 selΔ=0.0px、甩飞 slingΔ=(-5,0)、聚焦 focusΔ=0。档位量化后 smoke 确定性反而增强（旧 exp 路径结果为无理数）。二轮量程修订后复验三跑同绿（slingΔ=(-13,0)，首格 0.05→0.30 跳档的抖动折算增大，仍在容差 16 内）。
- 其余 smoke 无滚轮注入面（smoke-light 的 zoom 引用为游戏相机注释）；`io.MouseWheel` 流未动，层级列表等面板滚动行为不变。
- 真人手感：三轮迭代（初版 0.05/64 "仍不跟手" → 收窄 0.25/16 后）**用户认可收口（2026-10-14，"感觉好一点了，先这样"）**。后续可选刀口（未做）：1× 区撤微档改 ~25%/档（Godot 密度）、方案 C 连续模拟量缩放（消整格离散感）、AnimationPanel pickZoom 同模式统一。
