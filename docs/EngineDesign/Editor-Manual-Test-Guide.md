# Lemon 编辑器使用测试指南（手测清单 + 自动化覆盖）

> 定位：M4 全量功能的**使用级**验收清单——"判据链可跑"之外，把"能每天用来搭游戏"
> 逐项过一遍。按真实使用工作流分区（A 启动 → L 退出），每项给 操作步骤 与 预期结果。
>
> **怎么用**：
> - 条目标记 `[自动]` = 已被自动化覆盖（一键脚本 `tools/editor-regression.sh`，见 §1），
>   手测可跳过或抽查；`[手测]` = 必须真人操作（鼠标/IME/观感/OS 事件，无 UI 录制回放，
>   决议 R5）；`[手测·要点]` = 冒烟有部分覆盖但交互观感仍需人工。
> - 一轮全过约 **30–40 分钟**；只过 `[手测]` 项约 **20 分钟**。
> - 跑完把结果记 §4 运行记录表；发现缺陷进 DevLog（M4.6 教训：真人路径缺陷冒烟测不到）。
>
> 准备：`cmake --preset mac && cmake --build --preset mac`；准备一张外部 PNG（Finder 拖拽用）。

## §1 自动化一键回归（先跑这个）

```bash
tools/editor-regression.sh          # 全套：ctest + 8 项编辑器冒烟，末尾汇总 PASS/FAIL
tools/editor-regression.sh quick    # 快检：ctest + 基础冒烟 + 关闭状态机（约 1 分钟）
```

覆盖映射：数据层语义（资产库/向导/新脚本模板/备份恢复/Prefab/Undo 存档）= ctest
engine-tests；壳与面板渲染/字体/ID 冲突扫掠 = 基础冒烟；资产管线与热替换 = 资产链；
脚本装配/Play 沙盒逐字节 = 脚本链；量化判据（fps/热重载/冷启/stateBag）= `--final`；
退出状态机 = `--smoke-close`；场景 IO roundtrip = `--save-scene`/`--scene`；
**真人操作链路（快捷键/点选/复制删除 Undo/label-scrub/保存/Play/重命名/行拖拽挂父子/
目录进出+面包屑/命名布局/Console 标签+开关）= `--smoke-ui`**（21 项断言，M4.7d 起）。
