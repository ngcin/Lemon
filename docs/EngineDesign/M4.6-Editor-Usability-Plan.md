# M4.6 编辑器可用性加固规划（M4.5 收官后追加轮）

> 定位：M4 交付的编辑器满足全部**判据链**（M4-Editor-Plan §6 量化 PASS），但 2026-09-20
> 首次真人连续使用即暴露 3 个阻断级 bug（当日修复，commit `b7094a9`）——"判据可跑"与
> "能每天用来搭游戏"之间还有一轮差距。本分册规划这一轮：**不新增面板、不动渲染内核**，
> 只把现有功能的会话闭环与日常编辑效率补齐。
>
> **进度**：**M4.6a 会话闭环已完成**（2026-09-20，commit `2273e7f`；§4 九条目全落地 +
> 负向实验 + ctest/冒烟/终验零回退）。**M4.6b 编辑效率已完成**（2026-09-20；§5 七条
> 全落地：实体复制粘贴 / 资产右键（M4.4 已接，本轮验收确认）/ 拖拽导入 / 新建脚本
> 菜单 / 编译状态提示 / Console 编译错误解析 / FilePicker 手输与快捷钮；ctest 3/3
> （12986 checks）+ 冒烟/终验/--smoke-close 零回退；手测清单待真人过一遍）。
> 实施偏差一条：父节点双击与 ImGui 展开/收起语义冲突，父节点重命名走 F2/右键
> （叶子双击原样，§4-7）。

## §0 结论速览

| 项 | 结论 |
|---|---|
| 范围一句话 | 会话完整闭环（打开→导入→编辑→Play→保存→关闭 全程零命令行、零文档）+ 日常编辑效率件 + 交互路径自动回归 |
| 交付分批 | **M4.6a 会话闭环**（约 1 周）→ **M4.6b 编辑效率**（约 1–1.5 周）；观察项挂 M5 |
| 出口判据 | 新用户 30 分钟内零文档零命令行完成：新建项目 → 导入 PNG → 摆场景 → 挂脚本 → Play → 保存 → 关闭；全程交互路径冒烟 `errors=0` |
| 触发事件 | 2026-09-20 实测三修（§1）；共同根因 = **交互路径无自动回归**（冒烟只覆盖脚本化路径） |
| 砍单序 | 欢迎页降级为提示横幅 → 最近项目（保 3 条）→ 实体复制粘贴 → 编译错误点击跳转（保留红字文本） |

## §1 本轮实测缺陷复盘（2026-09-20，已修 `b7094a9`）

| # | 现象（用户实测） | 根因 | 修复 | 回归方式 |
|---|---|---|---|---|
| 1 | 点关闭按钮无响应；点一次"创建精灵/游戏对象"（场景变脏）后确认框才弹出 | 主循环退出裁决只有 `dirty` 分支消费 `exitRequested_`，**干净场景无退出路径**（anim-smoke 骨架遗留） | 退出裁决二分：脏场景确认（原样）/干净场景立即退出 | 手测 + M4.6a `--smoke-close` 注入 |
| 2 | 导入任何文件都报"导入失败（IO）" | 无项目状态 `AssetsRoot()` = `"/Assets"`（`root_` 空），拷贝到文件系统根必失败 | 菜单层守卫（可操作错误提示）+ `AssetDatabase::ImportFile` 底层守卫，双层拦截 | 手测（无项目启动点导入） |
| 3 | "打开项目..."菜单点了只打一条日志 | 菜单项从未接线（M4 按 `--project` 单会话设计） | FilePicker `.lemon` 模式 → 会话内切换全管线（watcher 先停再启 / 重建回调只注册一次 / 无 Game 清旧脚本宿主 / 脏场景先确认） | 手测 |
| 4 | （顺手修）Play 中 Ctrl+S 会把 **Play 世界**存进编辑场景路径——数据丢失级 | `playing_` 冗余显示态从未同步，`!playing_` 守卫恒失效 | `BuildUI()` 每帧对齐 `ctx_.Playing()`，7 处守卫一次救活 | 手测 |
| 5 | （顺手修）Edit 态按 ESC 即请求退出 | anim-smoke 骨架遗留（冒烟便利键） | ESC 边沿检测：Play 中 = Stop；Edit 态不触发退出 | 手测 |

**教训（进 DevLog）**：5 个问题全部位于"只有真人点得到"的路径——冒烟框架（--smoke/--final）
驱动的是数据与渲染，从不模拟菜单/关闭/快捷键。M4.6a 把三条关键状态机路径（关闭、
保存、打开）脚本化进冒烟，其余靠 §4 手测清单。

## §2 目标与非目标

**In**：
- 会话闭环补全：项目中心最小形态、向导目录选择、最近项目、标题栏项目/脏标记、无项目引导。
- 日常编辑效率：实体重命名、Undo/Redo 菜单接线、实体复制粘贴、资产右键重命名/删除、
  外部文件拖拽导入、新建脚本菜单、编译状态提示、Console 编译错误解析。
- 质量防线：交互路径冒烟扩展。

**Out（明确不做，维持既有推期）**：新面板、TilePalette（M6）、图集/切图（M6）、
AnimationEditor 等（M5/M6，见 M4-Editor-Plan §1 Out 清单）、multi-viewport（M5）、
B 线换装激活（探针转绿前不动，ADR-010）、逐字段 override（M5 ADR-009 修订）。

**量化判据**：

| # | 判据 | 目标 |
|---|---|---|
| 1 | 全程零命令行 | 新建项目→Play→保存→关闭全程不碰终端（启动除外） |
| 2 | 交互冒烟 | `--smoke`（含 M4.6a 扩展）`errors=0`；`--final` 全 OK 不回退 |
| 3 | 回归 | ctest 3/3；M4.4/M4.5 既有量化指标零回退（fps ≥45、热重载 ≤2s 等） |
| 4 | 手测清单 | §4/§5 验收清单逐项过（真人一遍，约 15 分钟） |

## §4 M4.6a 会话完整闭环（约 1 周）

| # | 内容 | 验收 |
|---|---|---|
| 1 | **无项目引导横幅**：无项目时中央提示"未打开项目"+ 两按钮（新建项目/打开项目），状态栏红字 | 启动即见；两按钮直达既有向导/选择器 |
| 2 | **FilePicker 目录选择模式**：`Open(..., mode=Dir)`——目录行加"选择此目录"按钮 | 向导父目录、打开项目起点均可用 |
| 3 | **向导接目录选择**：父目录旁"浏览..."按钮 | 新建项目全程零手敲路径 |
| 4 | **最近项目**：`$HOME/.lemon/recent.json` 记 5 条；File 菜单列出；`--project` 缺省时自动重开上次（可 `--no-reopen` 跳过） | 打开过的项目菜单直达；重启自动恢复 |
| 5 | **标题栏**：`<场景名>* — <项目名> — Lemon`（脏标记实时） | 保存/改动即时反映 |
| 6 | **FilePicker 模态化**：打开期间盖住主 UI（ImGui 顶层 flag） | 选择器开着点不到背后 |
| 7 | **实体重命名**：Hierarchy 双击名字进入编辑（Enter 确认/ESC 取消），进 Undo | 重命名后保存重开名字在 |
| 8 | **Undo/Redo 菜单接线**：Edit 菜单显示可用性（栈非空才亮）+ 快捷键提示 | 有操作后菜单变亮，点击生效 |
| 9 | **交互冒烟扩展**：`--smoke-close`（注入关闭请求：干净场景直接退、脏场景确认丢弃后退，两条断言）；保存/打开状态机断言并入 | 冒烟 `errors=0`；故意破坏退出裁决时冒烟变红（负向实验） |

**手测清单（15 分钟）**：无项目启动→点横幅新建项目（浏览选目录）→导入外部 PNG→摆几个
精灵→重命名→挂 SpawnerBehaviour→Play 刷怪→Stop→Ctrl+S→标题栏 * 出现又消失→点关闭
按钮（干净场景）秒退；再改脏→点关闭→确认框三键各走一遍。

## §6 观察项（不排期，条件触发）

- **切项目 spriteId 重编号**：会话内切换两个都有贴图的项目时，新项目资产触发红字自愈
  重编号（manifest 被就地重写）。彻底解 = 场景引用 guid 间接化（SpriteRef 存 guid，加载
  时查 manifest 映射）——与 06 §2 图集改造天然同点，**M5 评估**；过渡建议：贴图多的项目
  切换用重启。
- **dotnet build 主线程阻塞**：M4.6b 只加提示不改异步；若后续实测阻塞感明显（>2s 频繁），
  再评估后台编译 + 换装回主线程的拆分。
- **大场景 Hierarchy 性能**：>1000 实体时每帧全量遍历的帧率观察（vs-survivor M5 压测顺带）。
- **M4/M4.5 既有遗留**（本册不动）：B 线换装激活（探针）、逐字段 override（ADR-009）、
  multi-viewport 与 `--smoke` ctest 入口（09 §8）。

## §7 风险与砍单序

| 风险 | 缓解 |
|---|---|
| 范围蔓延（编辑器永远差一件小事） | 面板集与 Out 清单冻结（§2）；每批出口判据即手测清单 |
| 拖拽/标题栏等平台差异（macOS 先行） | SDL3 语义层接口；Windows 移植矩阵 07 登记验证点 |
| recent.json 全局状态引入新故障面（损坏/权限） | 解析失败 = 静默清空重来，不阻断启动 |

砍单序（触发即执行）：欢迎横幅降级为状态栏提示 → 最近项目保 3 条去自动重开 → 实体
复制粘贴（Ctrl+D 已够用）→ Console 错误点击跳转（保留红字文本）。
