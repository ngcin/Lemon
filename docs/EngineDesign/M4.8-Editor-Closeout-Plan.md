## §2 实现注记

- **a**：`ComponentMeta.removeFn` 为 M3 结构命令缓冲既有钩子；重置走
  `SnapshotComponent(before) → removeFn → emplaceFn → SnapshotComponent(after) →
  PushPropertyUndo`，与重命名同轨。`removeFn == nullptr` 的组件菜单灰显。
- **b**：记账在 `EditorContext::OpenScene` 成功路径集中落（picker/最近菜单/启动
  --scene 全覆盖）；存取走 nlohmann（.lemon/ 状态目录，gitignore 同 manifest）。
  `PendingSceneOp::RecentScene` + `pendingScenePath_`（确认后直达，不再弹选择器）。
- **c**：`ImGuiBackend::Init` 增 `persistLayout` 参数（默认 true）；EditorApp 按
  launch 注入标志传入 false。正常会话不受影响。
