# 后处理与战斗表现

两条不要混淆的线：**世界空间表现**（飘字/血条，走 sprite 管线合批，零 UI 框架成本）
与**全屏后处理链**（FX chain：bloom/色调/冲击波）。

## Fx 门面（飘字 / 血条）

`Lemon.Fx` 写呈现通道（不入状态哈希——纯表现不进回放）：

| API | 语义 |
|---|---|
| `Fx.Text(text, pos, color)` / `Fx.Text(number, ...)` | 飘字（上浮淡出，寿命 0.8s） |
| `Fx.Text(text, pos, color, style)` | 带样式（`FxStyle.Pop`：缩放/寿命/driftX/弹跳曲线） |
| `Fx.Crit(text, pos)` | 暴击字（默认放大） |
| `Fx.Miss(pos)` | MISS 字 |
| `Fx.Bar(g, frac, color)` | 实体头顶血条（sticky 锚定，实体没了自隐） |
| `Fx.Bar(g, frac, color, width, skin)` | 贴图血条（`FxBarSkin.Textured`：bg/fg sprite + 延迟条 + 高度） |

中文飘字走 TTF 烘焙字体页（project.lemon 的 `fxFont` 选定），缺字回退内置位图页。

## 全屏后处理链（PostFx）

质量档 **Med 及以上**自动开启，Low 档关闭（关链帧与无 FX 版逐位相同——「关 FX
零成本」是机器断言，不是口头承诺）。效果三件：

- **bloom**：双滤波三级降采样链（亮部柔光）；v1 是 LDR 语义（gamma 空间、阈值
  取近白像素）——HDR bloom 列 v1.1。
- **色调曲线**：合并进终段着色（fxFinal 一次采样做完）。
- **冲击波**：UV 扰动（屏幕空间波纹）。

两壳同链：编辑器 GameView 与 lemon-game 共用同一 PostFx 实现；FX 链接在光照
合成之后（受光的画面再进 bloom）。v1 无脚本面参数调节位（参数为引擎侧质量档
驱动）；过载时自动降档 FX 链先卸。

## 质量分级全景

帧时间 EMA 超阈值持续数秒 → 自动降一档（只降不升，防抖动）：

| 档 | 粒子预算 | lightRT | 灯上限 | FX 链 |
|---|---|---|---|---|
| Low | 20000 | 1/4 分辨率 | 32 | 关 |
| Med | 50000 | 1/2 分辨率 | 64 | 开 |
| High | 100000 | 全分辨率 | 64 | 开 |
