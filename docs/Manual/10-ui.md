# 界面（UI）

三层分工，按需选：

| 层 | 用途 | 入口 |
|---|---|---|
| 世界空间 HUD | 血条/飘字 | `Lemon.Fx`（见 [FX 页](09-fx.md)）——永远走 sprite 管线合批，**不进 UI 框架** |
| 快速 HUD 屏上文本 | 计时/计数/简单条 | `Lemon.Ui`（RtUi 通道，8 槽） |
| 完整界面 | 菜单/图鉴/对话/富排版 | RmlUi（`.rml` 文档 + `Lemon.UI` 门面） |

## 快速 HUD：Ui（RtUi 通道）

```csharp
Ui.Set("hp", "68/100", 0.68f, 0xFF30B0F0);   // 血条（着色 + 进度条）
Ui.Set("time", "03:25");                      // 纯文本（frac < 0）
Ui.Clear("time");                             // 删一行

Ui.ShowCards("升级三选一", "移速 +10%", "磁力 +25%", "射速 +20%");
int pick = Ui.CardPick();                     // 每帧轮询；-1 = 未选（读后即清）
Ui.HideCards();

Ui.ShowDialog("你死了", "重新开始");           // 单按钮对话框（B/C 留空）
```

key 稳定即同行覆写；建议卡片期间 `Time.Scale = 0` 冻结模拟（选完恢复）。

## RmlUi：完整界面

**一组件 = 一文档 = 一屏**：实体挂 `UIDocument` 组件，资产槽选 `.rml`，进 Play
声明式装载（换场即卸）。

- 文档与样式：`.rml` / `.rcss`（HTML/CSS 心智；`<img>` 可吃项目精灵，
  `rect` 属性切子图）。AssetBrowser 双击预览，rcss 改动热重载。
- 声明字段：`showOnStart`（装载即显）/ `modal`（模态）。

### C# 门面（`Lemon.UI`，提交制）

UI 调用先进 staging，**`UI.Apply()` 一次性提交**（当帧可见）：

```csharp
UI.Show("upgrade_cards", modal: true);
UI.SetText("upgrade_cards", "title", "升级！三选一");
UI.SetItems("upgrade_cards", "cards", "card", rolls);  // 模板行实例化
UI.Apply();
```

| API | 语义 |
|---|---|
| `UI.Show(doc, modal)` / `UI.Hide(doc)` | 显示/隐藏文档 |
| `SetText / SetAttr / SetClass / SetStyle / SetInnerRml` | 按元素 key 改文档 |
| `SetItems(doc, container, template, items)` | 列表/卡片批量实例化 |
| `UI.Apply()` | 提交缓冲（忘了调 = 屏上不动） |

### 事件（反向）

```csharp
UI.Events.Subscribe(ev => {
    if (ev.Kind == UiEventKind.Click && ev.DocStr == "main_menu")
        SceneManager.LoadScene("Scenes/Grass.scene");
});
```

事件种类：`Click / Change / Submit / Hover / DocumentReloaded`。实例级订阅用
脚本里的 `Subscribe(...)` 助手（OnDestroy 自动退订）。

## 选型建议

- 能用 `Ui`（RtUi）解决的屏上信息别上 RmlUi——零布局成本。
- 菜单/图鉴/带输入的界面用 RmlUi；模板 MainMenu/结算屏是现成参照。
- UI 状态不入状态哈希、UI 交互不入输入快照——界面随便改不影响回放。
