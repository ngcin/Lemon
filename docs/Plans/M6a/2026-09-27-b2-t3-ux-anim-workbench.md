# M6a 批② T3-UX：动画工作台 v3 交互重设计（2026-09-27）

Status: **done**（机器验收全绿；真人验收清单见 §6）；批次 = [b2 内容生产总计划](2026-09-25-b2-content-production.md) T3 的第四轮（T3 初版 → T3b 三通道 → T3c 集工作台 → **T3-UX 交互重设计**）。

## 0. 背景与用户驱动

T3c 交付后用户实测反馈："操作太不方便了"。三轮 AskUserQuestion 校准，痛点全中且点出两处核心割裂：

1. **选精灵图片太麻烦**：sheet 选择 = combo 列全部 sprite 的纯文字路径，几十上百
   个资产里翻找无缩略图。
2. **新建动作与选图割离**：「+ 新建动作」开大表单（段名/fps/循环 + 内嵌精灵表
   框选），表单整个替换右区、把选图"放到下面"——期望流 = **输入动作名（如
   idle）→ 点 idle → 右侧直接添加图片集或多张图片编辑**。
3. 帧细编辑不便（无法插中间、删除/换序点数多、改参数要跑底部编辑行）。
4. 布局拥挤（底部停靠竖向 8 行堆叠）、预览 96px 太小。

用户提供 Godot 参照截图两张（`docs/animation/`）：面板主从布局 + Select Frames 对话框。

## 1. 布局定版（Godot SpriteFrames 式 master-detail）

```
┌ 目标行: [目标 ▾（集优先）] [新建动画集…] ──────────────────────────────────┐
├ Animations: ──────────┬─ Animation Frames: ──────────────────────────────┤
│ 集名（窄输入）         │ [从精灵表…][+ 空帧][复制帧][删除帧] |⏮ ◀ ▶ ⏸|     │
│ [+新动作][改名][复制][移除]│ [fps][循环▾] [保存]                            │
│ [搜索框]              │ ┌────────── 大预览（fit ≤512，居中）──────────┐    │
│ ▸ idle                │ │ 拖 Assets 精灵入图 = 追加帧 · 底部信息角标    │    │
│   walk                │ └──────────────────────────────────────────────┘    │
│ （inline 新建: [idle_]）│ ┌ 胶片带（Ctrl+滚轮缩放 40..128，帧号在下）─────┐   │
└──────────────────────┴ └ [00][01][02]… [+拖入放置区]                     ┘   │
                         属性行: 帧 x/N · sheet▾(项带缩略图) · cell · 状态行    │
```

- 左列 190→230px（容纳搜索框）；裸 .clip 传统模式无左列，右区同款（向后兼容）。
- 竖向行数 8 → 3 层（工具条 / 预览 / 胶片带+属性行）；预览 96px 定值 → 吃满剩余
  空间（fit，上限 512、下限 64）。

## 2. 交互变更（现在 → 改后）

| # | 旧（T3c 及以前） | 新（v3） |
|---|---|---|
| 1 | 建段 = 大表单（名/fps/循环+内嵌框选），替换右区 | 左列 `+ 新动作` → inline 只输入名字，Enter 建空段入集并选中；**输入保持开 = 连续建段**；fps/循环在右区工具条随手改 |
| 2 | 选图 = combo 纯路径列表 | ① AssetBrowser 缩略图**直接拖进右区**（入格=换图 / 入带尾或预览=加帧 / 入 sheet 槽=换 sheet）；② 所有 sprite combo **项带 18px 缩略图** |
| 3 | 从精灵表弹窗：无全选、无缩放、只能行优先框选、按钮静态文案 | Godot Select Frames 式：全选/清空 + 框选(行优先)/**点选(按点击序 = As Selected)** + Ctrl+滚轮缩放（0.25..8×，超出可滚动）+ 动态按钮（"追加 N 帧"） |
| 4 | `+ 加帧` 只能末尾追加，插中间靠拖 | 插入语义：有选中 = 插到选中帧后（承接引用）；帧右键菜单 在之前/之后插入副本；`Ctrl+D` 复制 |
| 5 | 删帧/改参数全靠底部编辑行点按钮 | 键盘：`←/→` 移选 · `Ctrl+←/→` 相邻换序 · `Del/Backspace` 删（多选批量）· `Ctrl+D` 复制 · `Space` 播放暂停 |
| 6 | 单击选帧不动预览（双击才跳帧） | 单击选中即预览跟随；播放态胶片带上有游标高亮当前播放帧 |
| 7 | 集/段两个保存按钮分居两处（集头行"保存集" + 底部"保存"） | 工具条一个「保存」= SaveAll（段成功才连存集）；状态行统一 |
| 8 | 胶片带固定 56px | Ctrl+滚轮 / ± 按钮缩放 40..128px；`Shift+单击` 范围多选（Ctrl 点选保留） |

## 3. 键盘仲裁（框架级新机制）

`IEditorPanel` 新增虚函数 `CapturesGlobalKeys()`（默认 false，既有面板零影响）。
AnimationPanel 在 OnGui 记录 `keysFocused_`（窗口含子窗持焦点，Begin 失败先清防
陈旧 true）；EditorApp `BuildShortcuts` 对**实体级 Delete/Ctrl+D** 加
`!panelCapturesKeys` 守卫——防"面板里删帧顺手删掉场景选中实体"的双触发（全局
Ctrl+D 原本只挡 WantTextInput，无焦点守卫）。焦点值取上一帧（本帧快捷键先行于
面板绘制，滞后一帧无碍）；无头 smoke 面板从不聚焦 → 注入式 smoke-ui 零影响。

## 4. 实现要点与纪律沿用

- 数据模型**零改动**：.clip/.ani schema、ClipEdit 序列化、ClipTable/Animator2D
  全部不动（金回放/脚本测试零重录的根基）。
- 弹窗纪律沿用：保留的向导/表选择器/新建集全部**边沿触发**；段重命名弹窗删除
  （改左列 inline 输入，Hierarchy 同款 Enter/Esc 语义），模态数量 -1。
- Rescan 后条目引用失效——新代码全程 guid 重查（QuickCreateSegment/
  DuplicateSegment/SaveAll 同 T3c 口径）。
- 帧操作原语（InsertFrameAfter/Duplicate/DeleteSelectedFrames）单点实现，工具条/
  键盘/右键菜单三入口共用；降序删/尾起插防索引漂移。
- 空 .clip 落盘合法（解析侧允许空帧表，TryCreateClip 不拦；保存侧 ≥1 帧校验不
  变）——一键空段的地基，运行时对空段整条跳过（既有语义）。
- 图标传输控制 = `ui::IconButton`（IconKind Stop/Step/Step/Play|Pause）；主题
  token 无散落 ImVec4；新控件 PushID + 非空 ## 标签（无头 ImGui 错误计数归零的
  主约束）。
