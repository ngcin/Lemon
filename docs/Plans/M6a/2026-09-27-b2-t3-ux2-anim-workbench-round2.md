## 1. 基建改动（面板外）

- **FilePicker**：`OpenMulti(title, dir, filterExts)` 多选模式（Ctrl/Shift 累加、
  双击确认、底行"已选 N 项/打开"）+ 扩展名白名单过滤（目录恒显示）。`Open` 重置
  多选态——既有调用（场景 IO/导入）零影响。
- **IconKind** 尾加 Add/Duplicate/Repeat… 五枚（枚举尾插 = 既有索引稳定），
  BuildIconPage 各一段形状绘制（＋/双矩形/×/铅笔/放大镜）。
- **EditorApp**：`OpenAnimationCreateClip(destDir)` 桥接 → 面板 `StartCreateBlank`
  （向导空白页，落点 = 浏览目录）。

## 3. 从精灵表两段式流程（Godot Select Frames 对齐）

1. 「+ 添加帧 ▾ → 从精灵表…」→ 文件选择器（起始目录 = 当前帧 sheet 所在目录，
   快捷钮"项目 Assets"；过滤 png/jpg/jpeg/bmp）。
2. 确认/双击 → **选帧对话框**：左图区（网格实时重绘 + InvisibleButton 覆盖捕获
   拖动 + Ctrl+滚轮缩放 + 全选/清空 + 框选/点选序）+ 右参数栏（按块数/按像素，
   改动即清选区，显示 cell 尺寸与总块数）+ 底行动态按钮（已选 N 帧 · 取消 ·
   添加 N 帧/替换为 N 帧）。**添加时**才把网格写 .meta（连号块分配需 Rescan →
   guid 重查后加帧）。
3. 项目外文件自动导入（落点 = 集目录/浏览器目录）；项目内未登记文件 Rescan 收编。

## 6. v3.2 热修（同日第三轮：用户截图"帧全在下面、右侧空白无法编辑"）

截图取证（裁剪放大逐区核对）定位根因：**Animation 窗口被拖成 ~300px 窄窗**（编辑
器其余为空停靠区），固定 230px 左列把右区压成 ~60px——工具条/保存/帧网格全部溢出
裁切，视觉即"右侧空白、帧跑到底部"。宽窗下布局本身无恙，但布局对窗口宽度零防御
是工程缺陷。修复（窄窗自适应三件套 + 两处顺手硬化）：

1. **窄窗自适应**：可用宽 ≥480px = 左右并排（列宽 = min(230, 30% 可用宽)）；
   更窄 = **上下堆叠**（动画列变顶部 38% 高横条，右区在下方）。
2. **右区整体进 `##right` child**：内容超宽时出滚动条（可滚到被裁的控件），
   替代 v3.1 的直接裁切丢失。
3. **「保存」提前**到「+ 添加帧」旁（窄窗工具条溢出时保命键最先存活）。
4. 开集**自动选中首个动画**（旧版回落空提示行——双击开集"看不见任何东西"的
   放大器；双击具体 .clip 的 SelectSegment 语义不变）。
5. 用户侧提醒：截图中的编辑器其他面板全部关闭、Animation 窗口过窄——把窗口
   拖宽（或拖回底部停靠位）即可恢复常规双栏形态。

## 7. v3.3 设计修复（同日第四轮：跨集同名动画互相覆盖 + "编辑条目丢失重扫无效"）

用户实测：player.ani 与 player1.ani 都有 run 动作，Assets 下只有一个 run.clip，
后保存的覆盖先保存的；另一处保存报"编辑目标条目丢失（重扫后重试）"重扫无效。

**根因（用户判断正确——是设计问题）**：动画 .clip 按裸名落集所在目录，跨集同名
（每个角色都有 run/idle 是常态）撞同一个 `Assets/run.clip`。三个叠加窟窿：

1. TryCreateClip 撞名守卫只查内存 DB——磁盘孤儿文件（DB 不知情）会被
   WriteFileAtomic 的 POSIX rename **静默覆盖**。
2. 墓碑复活语义：`Assets/run.clip` 被删过后重建，新动画**继承旧 guid**——
   两个集的 run 被接到同一文件/guid，后存覆盖先存。
3. 文件被删/接管后，另一集 .ani 里的引用成悬空墓碑——重扫永远救不回，
   即"条目丢失重扫无效"。

**修复**：

- **集内动画文件落位改为集子文件夹**（`Assets/player.ani` → 其动画在
  `Assets/player/run.clip`）：跨集同名从路径上隔离；集成员关系语义不变（仍是
  .ani 显式引用——T3c 否决"目录=作用域"的决策不受影响，文件夹只是存放位）。
  四处落位统一：集内新建（QuickCreateSegment）/ 复制（DuplicateSegment，源在
  旧位置也归位）/ 重命名（CommitSegRename）/ 新建集并建首段。
- TryCreateClip 硬化：**磁盘孤儿拒写**（exists 即拒，防静默覆盖）+ **建父目录**
  （子文件夹首次落盘）。
- 旧集（动画散在 Assets 根）向后兼容：引用按 guid 不断；改名/复制时顺手归位
  到集子文件夹。
- SaveAll 悬空错误信息可操作化：指明"左列标悬空 → 右键从集移除 → 重建（落
  集子文件夹）"。

**用户项目修复指引**（存量坏档）：打开报错的集 → 左列悬空动画（标「悬空」）
右键「从集移除」（或删除文件）→ 在两个集里各自重建 run（新文件分别落
`Assets/player/run.clip` 与 `Assets/player1/run.clip`）→ 重新选帧保存。
