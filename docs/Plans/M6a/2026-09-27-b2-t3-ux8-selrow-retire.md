# T3-UX8 属性行退役：右区底部"帧x/n · 路径 · 删除此帧"整行删除

2026-09-27 · 批② 动画生产线 · 用户走查报点（截图指认右下状态栏）讨论后定案。

## 背景（逐项对账）

用户指认右区底部一行（帧 2/12 · 路径 · 删除此帧(Del)）"删除跟上边重复、这里
也换不了图、多余"。对账结论：

| 内容 | 冗余度 |
|---|---|
| `帧 x/n` 计数 | 纯重复——预览条已有 `帧 x/n · 秒/帧 · 总长` |
| `删除此帧 (Del)` | 纯重复——全面板第 4 个删除入口（工具条/键盘 Del/胶片带右键） |
| 路径"标签" | 实为换源图下拉（带缩略图）+ 旁边全 UI 唯一 cell 数字框；但用户读成静态标签 = 交互不可发现的实证，换图主通道已是拖图入胶片带格 |
| 多选态 已选N/删除选中/全不选 | 删除同冗余；胶片带有高亮反馈，点单帧即清多选 |

## 决策（用户拍板）

- **整行退役**。"换 cell 的需求几乎没有，要更换就删除了重新添加；功能加太多
  又用不到会造成干扰，我们追求的是稳定"——cell 数字调档能力接受损失（切片表
  内微调 cell 从此走"删了重加/从精灵表重选"）。
- 参考引擎佐证：Unity 动画窗 / Godot SpriteFrames 均无底部单帧属性行。
- 无选中态的键盘提示不丢：并入帧列表标题行（本来就有交互提示位）。

## 改动

- `AnimationPanel.cpp`：删 `DrawSelectedFrameRow` 整函数（~90 行）+ 调用点 +
  `kRowPreview` 常量；`##strip` child 高度 `-GetFrameHeightWithSpacing()` →
  `0`（底部不再预留一行，帧网格吃满）；帧列表标题行扩键盘提示
  （←/→ 移选 · Ctrl+←/→ 换序 · Del 删 · Ctrl+D 复制）；工具条 复制帧/删除帧
  补快捷键 tooltip；6 处陈旧注释清理（文件头/右区结构注释/集失败状态去处）。
- `BuiltInPanels.h`：删声明。
