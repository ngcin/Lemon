# M7c 批③ — 编辑器 UI 国际化（i18n：中英统一管理 + 即时切换）

Status: done（机器面 ✅ 2026-10-08——构建零警告、单测 34,435、ctest 4/4、双语言 `--smoke` PASS、双语言截图视觉核验过；真人走查 ✅ 2026-10-10 用户过（[验收记录](../../DevLog/2026-10-10-acceptance-m7c-b2-b3.md)））

## 0. 背景与目标

用户反馈（2026-10-08）：编辑器菜单/操作中英文混杂（中文硬编码 ~207 处 + 英文硬编码 ~122 处，散落 ~15 个 ImGui 调用文件），要求统一管理并支持切换语言显示。方案讨论拍板：

- **覆盖范围** = 编辑器 UI 文案 + 面板名/反射字段显示名映射（Inspector 里组件/字段显示中文）；日志/注释/游戏模板不动。
- **存储** = JSON 文件（`Editor/Strings/<lang>/<module>.json`，改文案免编译；加语言 = 加目录）。
- **切换** = 菜单即时生效（ImGui 每帧查表），持久化到 `~/.lemon/editor-settings.json`，默认 zh-CN。
- **术语铁律**（用户二轮补充）：**译名与常见引擎（Unity/Godot 官方简中）一致，不自造**——Assets=资源、Inspector=检查器、Hierarchy=层级、Profiler=性能分析器、Sprite=精灵、Prefab=预制件、Audio Mixer=音频混音器 等。

## 1. 落地物

| 件 | 位置 | 说明 |
|---|---|---|
| tr 模块 | `Editor/Localization/Localization.h/.cpp` | `tr(key)`（当前语言→en→key 三级回退，缺 key WARN 自查）；`trFmt(key,{args})` `{0}` 占位；`SetLanguage` 热切换；启动扫描 `Strings/<lang>/*.json` |
| 设置持久化 | `Editor/App/EditorSettings.h/.cpp` | `~/.lemon/editor-settings.json`（recent.json 同款口径：损坏静默回默认） |
| 翻译源 | `Editor/Strings/{en,zh-CN}/*.json` | 12 模块 × 双语言 = 每侧 **601 key**（chrome 114/anim 141/assets 54/display 180/inspector 38/hierarchy 16/filepicker 11/profiler 14/console 8/viewport 8/panels 8/common 9） |
| 对齐校验 | `Editor/Strings/check_alignment.py` | en/zh key 集合逐模块比对，非零退出码（可挂 CI） |
| 语言切换入口 | Window 菜单 →「语言」子菜单 | 语言列表来自已装载表；选择即生效并落盘 |

**窗口身份锚定**：所有面板/工具窗标题改 `<本地化名>###<英文标识>`（ImGui `###` 后段 = ID）——切语言只换显示，停靠布局/imgui.ini/FindWindowByName 全不受影响；DockBuilder 与 ClosePanel 仍用英文标识。弹窗 OpenPopup/BeginPopupModal 同帧共用同一 `tr` key。

**反射显示名**：`display.<Component>` / `display.<Component>.<field>` 键（display.json 覆盖 ComponentCatalog 全量 32 组件 + 144 字段）；渲染处 helper 先查 key、未命中显原名（不进注册表——注册名是序列化稳定标识，绝不动）。

## 4. 已知尾巴

- Engine 侧错误串（`assets::ValidateAssetName`/AnimAsset 解析错误）在 en 界面下仍中文——Engine 本地化另立批（涉及游戏侧文案机制）。
