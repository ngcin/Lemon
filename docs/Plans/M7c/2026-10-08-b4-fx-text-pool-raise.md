## 0. 背景与拍板

- 候选池原登记「飘字池提额（若一局满屏跳字触顶）」——观察哨形态（上限 256，
  触顶症状 = 数字互相覆盖，非崩溃）。2026-10-08 与用户讨论机制后拍板：不待触顶
  直接提 512 收尾（容量翻倍 ≈ +12KB 常驻；真实成本 = 每帧多画存活 sprite，
  bench 实测无感）。
- 同日相关拍板：动画 auto-slice **取消**（域内规整网格已覆盖 / 域外打包图集应走
  元数据导入而非像素猜测，总览页否决注）——候选池同步瘦身。

## 3. 机制备注

- 池上限兼任 runaway 保险丝（03 §10）：512 仍是环形淘汰兜底，误发洪水只会互相
  覆盖，不会无底砸帧率——不设运行时开关（constexpr），提额即重编。
- 头文件常量注释带本批号与「bench 复跑无降」实测结论。

## 4. 附带发现：批③ i18n 英文态回归（登记不本批修）

- **现象**：`--smoke-anim` 在语言=en 时 `row=NO` 稳定复现（3/3）；zh-CN 稳定绿
  （3/3）。`row` = 选帧对话框底行越窗锁（2026-09-28 用户截图报「替换为」出窗的
  回归锚，EditorAppSmoke.cpp f80：替换钮右缘须在模态窗内）。
- **根因**：底行 = 左侧 meta_hint 提示文本 + 三钮（取消/添加/替换为，各 150px）
  右对齐让位公式（`AnimationPanel.cpp:929`）。zh 文案与批③ 前逐字相同；en 的
  `anim.pick.meta_hint`（"The image .meta is written when adding (applies
  project-wide)"）远宽于中文 → 剩余宽度放不下三钮整行 → 最右「替换为」越窗。
  即：**布局按中文宽度调的死，英文态触发**——越窗锁抓住的正是它要防的形态。
- **证据链**：HEAD~1 构建（不含本批改动）同败（非本批引入）；批③ 门禁跑的是
  双语言 `--smoke`（基础冒烟不含 smoke-anim），故漏网。
- **测试面同问题**：smoke 系列未固定语言，`~/.lemon/editor-settings.json` 当前
  为 en → 回归结果依赖机器语言设置，门禁不可复现（本机 zh 下全绿、en 下必红）。
- **处置**：登记 M7c ⑤+ 候选池。修法两件：① 底行布局对任意语言宽度自适应
  （提示独占一行或按剩余宽省略）；② smoke 固定语言（或 anim/ui 链双语跑）。
