## 1. 输入与定形（用户 2026-10-16 拍板）

- **动因**：ARPG 受击/死亡全局中断 = 每态一条边（Duelist 实测 9/13 条），画布不可读；
  Unity Mecanim 与 Cocos Marionette 均以 Any State 治此族，Godot 无此节点（惯用代码
  直跳——本引擎 C# `Anim.Play` 同型出口已有，ADR-013 D1 脚本优先）。
- **求值序定形**：**any 边先于状态边评估，组内保持文件序，首条命中即切、每 tick
  至多一条**（Unity/Cocos 全局中断优先口径；实现 = 编译期 any 边稳定前置 →
  AnimGraphSystem 单遍扫描语义即得，无 any 边的档序与文件序逐位一致）。
- **白捡语义**：any→X 命中时若当前已在 X，`cid != an.clipId` 守卫自然 no-op
  （= Unity "Can Transition To Self" 默认关，无需额外设计）；命中即消费 trigger
  （含同态 no-op）——ADR 文档化即可。
- **红线维持**：ADR-013 D4 修订仅开 any-state；blend tree / layers / sub-FSM 仍禁。
- **同批搭车**：review B16（自环禁令，三入口 + schema 拒——仓内零存量已核）+
  B17-1（边锚点从节点中心改边界交点——治"线从节点底下穿过"乱源，箭头投影同款数学）。
- **重启语义归位**：图路径同段切换 no-op、脚本路径 `Anim.Play` 同段 = 重播
  （SDK Anim.cs:7）——"重启当前动画"明确归脚本域，图不欠此能力（B16 定性依据）。

## 顺手修（用户实测二/三/四/五/六/七轮，同日晚——随批⑪ 一并提交）

- **Inspector 动画图/动画参数可读性（七轮，用户报障"作为开发者完全没法理解"
  ——截图实锤 GUID 裸十进制 + 匿名参数槽）**：两处根因——① `kEdAnimGraph` 只挂
  tooltip 未挂 `ControllerRef/AnimSetRef` hint（T3d 批① 建好的 `DrawGuidSlot`
  资产槽控件一直在等，没接线）→ 补 `ED_CTRLREF/ED_SETREF` 宏接通：路径名显示 +
  下拉全列/AssetBrowser 拖入/右键清空；② AnimParams 静态字段表带不了控制器词面
  → Inspector 组件级特判 `DrawAnimParamsBody`：按同实体 AnimGraph.controllerGuid
  解析 .controller 参数表（(guid,hash) 单槽缓存），**具名行 = 名字 + 类型
  （float/bool/trigger）+ 值**——编辑态只读显控制器默认（RT 组件不落档），Play 态
  实时读写（= v1.1"参数实时调"最小落地：直写 Play World 组件，图下一 tick 消费；
  trigger = 激发按钮，写 1 命中即清）。未绑控制器/解析失败 = 灰字提示。不进
  属性轨/Undo（RT 无落盘语义）。i18n +4 键（insp.animparams.*）。
- **运行时验收场 anytest.scene（六轮后，用户点名"建 scene 测功能"）**：专用单实体
  场景（Monster02 全五段绑定 + Duelist 用户手档拓扑）+ `AnyStateProbeBehaviour`
  时间线探针（自动驱动 + 逐相断言 + 无头出口：`[anytest]` 结论行 + 存档键
  `anytest.verdict`）。六断言全绿：入口 Idle / speed→Walk / attack→Attack（状态边
  基线×2）/**Attack 段中 hit→Hit（any 边全局中断——核心断言）**/Hit 段末 exitTime
  回 Idle / death→Death 终态驻留。观察项（不计分）：Death 中再发 hit = 切 Hit——
  拓扑事实（any→Hit 对 Death 生效），"死亡中不受击"确认为伤害脚本代码侧门职责。
  跑法 = `lemon-editor --project demo/svr-test --scene
  demo/svr-test/Scenes/anytest.scene --smoke --play --frames 800 --no-reopen`。
  坑两条：行为类必须在 `GameMain.Configure()` 显式 `Behaviours.Register<T>()`
  （无自动扫描——"类型未注册（跳过）"红字即此）；`--scene` 路径按 **cwd** 解析
  非 project 相对；`--play` 需与 `--smoke` 同挂才进 Play（EditorApp.cpp:379）。
- **Any 落键后交互死区（六轮急修，五轮引入）**：Any 首拖惰性落 `"*"` 档键后，
  `hitNodeLi` 仍把 `"*"` 当状态节点命中 → 下游 `StateIndex("*") = -1` 使点击/
  再拖/右键菜单全部静默失效（"拖一次就再也拖不动"）。修法 = 遍历面三处跳过
  `"*"`：`hitNodeLi`（Any 命中走 `hitAny`）、把手扫描节点环（Any 把手已前置
  扫描）、FitCanvas 节点环（Any 专用块入界）；节点绘制环本就 `si < 0 continue`
  天然免疫。教训 = 保留键进共享容器时，**所有"状态节点语义"遍历点都要清单化
  排除**（grep `edit_.layout` 逐点核）。
- **Any 节点可拖 + 持久化 + 删除（五轮）**：屏幕空间固定左上（⑪ 初版 Unity 同款）
  实测调整不便——Any 改图空间普通节点位：体可拖（`kAnyDragNode` 哨兵复用状态拖动
  通道，网格量化/撤销"松手拍一次"同款）；位置随 `editor.nodes` 保留键 `"*"` 持久化
  （**惰性落位**：首次实际位移才写键——未拖过的档零污染；规范序 any 恒居尾 =
  roundtrip 等值前提，解析/序列化/NormalizeLayout 三处同构）；缺省位 = 布局包围盒
  左外侧（自动布局 x≥0 恒不重叠），F 适配入界。右键「删除任意节点（清空 N 条全局
  边）」——节点本体 = 建边入口恒在（Unity Any State 同款不可移除），删除语义 =
  清空 any 边（PushUndo 可撤销）。单测 +4（`"*"` 解析归一/序列化字面/roundtrip
  不动点/坏项容错）。
- **直线边（四轮定形）**：贝塞尔拱弧实测不友好——退役。边 = 直线（边界交点端点）；
  双向对 = 各平移一侧的**平行双线**（10px/侧，字符串序定向）；同向叠边 8px/条外错；
  箭头恒在直线中点沿方向（同轴天然成立）；命中 = 点到线段距离（24 段曲线采样
  退役）。走线模型自此 = 直线 + 侧向平移，无曲线参数。

- **四向把手（三轮）**：节点/Any 节点每边中点各一个拖线圆点（hover 显现四个，
  8px 激活半径、B1 防误触阈值沿用）；落点端渲染仍按连线方向自动求边界交点——
  端口不进 schema，零数据面改动。`edgeDragSide_`（0 右/1 左/2 上/3 下）记抓取
  侧供幽灵线起点；右键「新建出边」起步默认右侧。
- **双向对分离（三轮）**：A→B 与 B→A 此前同弦渲染完全重叠（箭头/标签/点选互
  踩——用户报障）。修法 = 双向对按状态名字符串序定向，控制点各向弦垂直一侧
  拱 22px（确定性、与相机无关）；同向叠边偏移同步改沿弦垂直向（垂直布局对
  也能错开）。any 边无双向对（to 不接受 "*"）。

- **箭头中线化（review B18 级视觉 bug）**：端点箭头按弦向定向，而贝塞尔端点
  切向（控制点水平偏移决定）≠ 弦向 → "线斜穿箭头、不同轴"（用户实测报障
  "箭头有些奇怪，连接线没在箭头中间"）。修法 = Unity 同款**箭头画在曲线 t=0.5
  处、沿切向定向**（切向闭式 ∝ b+c2−c1−a），箭头中线与曲线局部同轴；中点小圆点
  退役（箭头即更大的点选参照）；选中态箭头 9→11px。视觉几何无像素断言（B17-1
  同口径），渲染面由 smoke 探针覆盖。
- **Duelist.controller 按讨论方案重连（用户拍板 8 边拓扑）**：any→Death（文件序
  第一，死亡优先）/any→Hit/Idle↔Walk（speed 阈值）/Idle+Walk→Attack（trigger）/
  Attack→Idle、Hit→Idle（段末）+ 手工 editor.nodes 布局（Death/Hit 上排贴 Any、
  Idle/Walk/Attack 主行）。行为差异注记：any→Hit 现覆盖 Death 态（此前 Death 无
  出边）——死亡中不受击 = 代码侧门（伤害处理 gate，Unity 同款惯例），svr-test
  脚本面自管。
