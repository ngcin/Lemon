## 3. 段内排序与全局位次

- **批内顺序**：⓪（设计）→ ①（组件数据面，渲染零消费——先落位锁序列化/镜像，再动渲染）→ ②（编辑器竖切——最快可见回路）→ ③（lemon-game + 完整光源类型面）→ ④（后处理复用设施）→ ⑤（消费与真人验收）→ ⑥（性能终测收口）→ ⑦（文档站收官）。
- **全局新序**：M7c ✅ → **M8** → M9（Tilemap+TD）→ M7b（发行侧）。不变（08 文首注记口径）。
- **可调点**：批③ lemon-game 接入可提前与批② 并行（不同文件域）；批④→⑤ 现序维持（2026-10-11 评审：真人走查须覆盖光+FX 合成观感，对调会使走查批准的画面随后失效——原“可对调”注记收回）。W5 真机 GPU 窗口出现时顺跑批③ Windows 面。**排程注记（2026-10-11 评审）**：批⑤ 真人走查与批⑥ #M4 Windows 真机轮为两个人肉依赖窗口，可合并排期一次到位；soak 2h 为挂机项且批⑦ 不消费其结果，批⑥ 后半与批⑦ 可部分并行压缩段尾。
