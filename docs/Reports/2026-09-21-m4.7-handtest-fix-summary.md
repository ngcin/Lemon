# M4.7 手测修复总结（五轮全记录，2026-09-21）

> 对 M4.7 编辑器打磨期间真人手测暴露问题的完整归档：**6 大类 14 个问题**，
> 全部修复并回归验证（`tools/editor-regression.sh` 10/10 多轮连跑）。
> 逐轮实施细节见 `docs/DevLog/` 当日各条目；规划见
> `Plans/M4/2026-09-21-m4.7-ui-polish.md`。

## 一、崩溃与数据安全

### 1. 空实体 + SpriteRenderer 闪退（AtlasRegistry::GetSprite 断言）

- **现象**：空实体添加 SpriteRenderer 即崩，`spriteId != 0 && spriteId <= sprites_.size()`。
- **根因**：spriteId=0（未赋精灵）只判了上界没判 0。
- **修复**：`ViewportRenderer::WorldBoundsOf` 与引擎 `Renderable` 提取循环加
  `spriteId != 0` 守卫。语义对齐 Unity：Sprite=None 合法，只是不渲染。

### 2. Transform2D 飙到天文数字（43555688, 1363321）

- **现象**：几乎没操作 8 向拖动，坐标 exploded。
- **根因**：三个缺陷叠加放大——
  1. ÷2 投影模型：arm 时手柄跳 2×，多次拖拽连乘；
  2. 无钳制：乘法误差无上限；
  3. 子实体把**世界坐标**直接写进本地 pos（父链当放大器逐次累乘）。
- **修复**：
  1. **比例跟随模型**：arm 捕获 d0，hx' = hx0·(d·k)/max(2, d0·k)——起步零跳变、
     手柄 1:1 跟随鼠标；
  2. 硬钳 [2 世界 px 半宽， kMaxScale=200]；
  3. 世界意图（锚点 + 本地轴新半尺寸）经 R(−pw.rot) 与 pw.scale 逆映射回本地
     （TRS 复合之逆，与 ComputeWorldTransform 同约定）。

## 二、交互全灭

### 3. 移动/旋转/缩放/滚轮全部无响应

- **根因**：ImGui 1.92 `WantCaptureKeyboard` 语义变更——只要有窗口持有焦点即为
  true，编辑器内**恒真**，`canInteract` 永假。自 1.92 升级即存在。
- **修复**：输入门改用 `WantTextInput`；代码注释记录该语义，防再犯。

### 4. 无项目中央卡抢走视口点击

- **修复**：中央卡加 × 可关闭（`noProjectCardDismissed_`）。

## 三、相机与视图

### 5. 缩放方向反、放大后找不到对象

- **修复**：滚轮前推 = 放大（`zoom *= exp(wheel·0.12)`，钳 [0.05, 64]）；
  有选中 = 以**对象中心**锚定（缩放前后屏幕位置不动），无选中 = 鼠标点锚定。
  （本轮为无条件对象中心锚定；后由 #6 加"视野 ±25% 余量"门，视野外退回鼠标锚。）

### 6. 相机甩飞（center=(12333,139304)、visible 0、原点红线消失）

- **现象**：滚轮放大缩小几次后 Scene 里精灵、红线全部消失。
- **根因**：缩放锚点无条件取选中对象中心——对象在视野外（或父链携带 #2 的
  爆炸损伤，Inspector 显示的 pos 是**局部值**）时，每格滚轮把相机向它拖
  (1−1/k)·距离；距离 1e6 时一格 ≈ 1.1e5 单位。
- **修复**：选中对象屏幕锚点在**视野 ±25% 余量内**才锚其中心，否则退回鼠标锚
  ——视野外对象永远无法拽动相机。红线/精灵消失只是原点出视野的结果，非独立 bug。

### 7. 迷路后找不回（按 F 没反应）

- **根因**：F 聚焦被"鼠标悬停 Scene 窗口"门挡死——在 Hierarchy 选中后按 F 无效。
- **修复**：F 去 hover 门（仅 WantTextInput 拦截）；**空选中 = 聚焦全部可绘制
  实体**（回家键）；角标 visible=0 且有选中时提示"选中对象在视野外 —— 按 F 聚焦"。

## 四、渲染视觉

### 8. 格子忽大忽小 / 忽有忽无

- **根因**：1/zoom 世界宽网格线不吸附像素——线骑在两物理像素之间时各得 ~50%
  覆盖，α70 网格混完后几乎隐形 → 一段段"空带"，越小越密越明显。
- **修复**：**网格 v4**——所有线吸附到 RT 像素中心、宽度恒 = 1 物理像素
  （AA-free、任何缩放下等宽等距等亮度）；间距自适应（缩远翻倍防密、拉近减半
  加密）；α 提升（kGridColor α110 / major α150，仍在冒烟灰带内）。

### 9. 网格样式乱（无主轴区分）

- **修复**：Godot 样式——原点 **X 红**横线 / **Y 绿**竖线（同宽不透明），其余
  均匀细线。

### 10. 视窗外层 / Hierarchy 空列表滚动条

- **修复**：Scene/Game 窗口 `NoScrollbar | NoScrollWithMouse`（滚轮留给缩放，
  ImGui 滚轮冒泡会推挤布局）；Hierarchy 去多余 AlwaysVerticalScrollbar。

## 五、手感

### 11. 8 向拖动不丝滑（非帧率问题）

- **根因**：`gridSnap_` 一 flag 两用——同时 gate 网格显示与全部拖拽吸附且默认
  开。看得见网格就被迫吃全套台阶：平移 8 世界单位/档、旋转 15°/档、8 向 resize
  **半宽** 8 单位/档（总尺寸 16 单位，zoom≥1 时每跳 8-16px）、Scale 0.25/档。
  Godot（磁铁）/Unity（Ctrl）默认都不吸附。
- **修复**：
  1. 解耦为 `gridVisible_`（默认 true，纯视觉）+ `snapEnabled_`（默认 false）
     ——拖拽全模式连续丝滑；
  2. **按住 Ctrl 拖拽 = 临时取反吸附**（`snap != io.KeyCtrl`）；
  3. 工具栏拆两钮：# 网格显示 / 新 **Magnet** 磁铁图标（形状页 17→18）吸附
     开关，tooltip 注明档位与 Ctrl 临时取反。
- **其余环节确认本就正确**：比例跟随起步无跳变、4px arm 阈值与 Godot 同级、
  拖拽逐帧路径无分配无 O(n)。

### 12. （隐患）DPI≠1 时拖拽/拾取/锚点整体偏 2×

- **根因**：SDL3 后端透传窗口"点"坐标，而 `ScreenToWorld`/缩放锚点/平移按 RT
  "像素"归一——Retina 下全链路 2× 偏差（也会被感知为"拖拽不跟手"）。
- **修复**：`ptToPx` 统一换算（mouseWorld / 缩放锚点 / 平移 delta）；
  DPI=1 行为不变。

## 六、新功能

- **Select 模式（Q）**：Godot 式 8 向手柄（4 角 + 4 边中点，白圈红点，hover
  反馈），单选激活；可拖动移动 + 8 方向调整大小（对侧锚定）；悬停光标 8 向映射
  （NS/EW/NWSE/NESW）。
- **工具切换**：Q 选择 / W 移动 / E 旋转 / R 缩放（点击 + 快捷键）。
- **平移**：中键拖拽或空格+左键拖拽。
