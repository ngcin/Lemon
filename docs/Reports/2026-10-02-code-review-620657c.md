## 0. 结论 TL;DR

- **基础质量是好的**：分层纪律（Vulkan 零泄漏、依赖向下、C++/C# 边界两条通道）未见违例；音频命令表 staging 语义、组件冻结、锁序实现与设计文档一致；构建 + 全量回归双绿。
- **两条高危同一根因**：引擎层没有 `pausedAll` 的复位兜底（`Shutdown()`/`StopAll()` 均不清），此前的 c353af2 只在编辑器宿主侧打补丁；会话内「暂停 → 返回主菜单 → 再开局」这条路模板与 demo 都没写回 `Audio.Paused=false`，新 BGM 声部以挂起态出生，整局静音。
- **中危集中在三类**：暂停语义无引擎层兜底、失败路径静默无告警（换片失败、meta loop 热改失效、removed 事件不可达、拷贝不查错）、新增入口漏挂初始化清单（重编译重试 Play 漏音频双挂点、smoke-audio 漏 recent.json 守卫）。
- **回归绿灯含金量有缺口**：fade 终结与流式双声部叠加两处断言分别被自然播完 mask / 恒真（期望值为 0）；SDK 级组音量桥经脚本零覆盖且注释虚标；meta importer 段探针只打印不裁决。

## 1. 建议先处理（按影响排序）

1. **引擎层收口 `pausedAll` 残留**：`AudioEngine::Shutdown()` / `StopAll()` 增加复位兜底（或引擎侧会话边界统一复位），而非继续在宿主侧打补丁——一处修掉两条高危（#1、#2）并消除 M7a 独立运行时再踩的陷阱（#14）。
2. **补齐「重新编译并进入 Play」的音频双挂点**：`EditorAppChrome.cpp:837` 直调 `EnterPlay()` 漏 `MountPlayAudio/WirePlayAudioBackend`，该路径整段无声（#9）。
3. **修正音高微扰除数**：`AudioEngine.cpp:303` 一行修（`8388607.0f` → `16777215.0f`），当前实际扰动区间为声明的 2 倍上界且整体偏尖（#3）。

## 2. 共性观察

- **暂停语义无引擎层兜底**：`pausedAll` 生命周期的复位散落在宿主侧（编辑器 MountPlayAudio 清、游戏侧没人清），引擎层 `Shutdown`/`StopAll`/`Clear()` 三个可能的位置全部缺失或为死代码（#1/#2/#14/#7）；编辑器 `paused_`（sim 侧）与音频侧复位不同步还产生「画面冻结、BGM 照响」错位态（#28）。
- **失败路径静默**：换片起播失败永久静默不重试（#5）、.meta loop 热改永不生效于已烤 clip（#8）、删除资产的 removed 事件永远不可达（#7）、`fs::copy` 不查错误码（#21）、播种写盘失败误报为用法错误（#37）——与引擎「响亮失败」的既有纪律不一致。
- **新增入口漏挂初始化清单**：重编译重试 Play 漏音频双挂点（#9）、smoke-audio 漏 injectionSession 守卫污染 recent.json（#10）——新入口复制既有挂点清单时没有机械保证，值得在 M7a 前立一份「进 Play 必挂清单」。
- **回归绿灯的含金量**：#11/#12/#24/#25/#34/#35/#36 共 7 条测试面发现，其中两条为断言真空（mask/恒真），意味着这些路径的"全绿"不构成行为锁。
- **镜像默认值坑家族**：AudioSource.Group 的 C++/C# 默认分歧（#17）是 Flags 之后第二例，建议把「整写组件须显式设全字段」写进 04 分册或 SDK 注释。

**#3 · Engine/Audio/AudioEngine.cpp:303 · 已确认**
问题：音高微扰的均匀数映射除数错一倍：24 位随机值除以 2^23-1 而非 2^24-1，u 落在 [0,2] 而非 [0,1]，实际扰动区间为 [−range, +3×range]——默认 ±2% 实为 −2%..+6%（上界约 +1 个半音，整体偏尖），且 `SetPitchJitter` 封顶 0.25 时 rate 可达 1.75。
证据：line 303 `const float u = float(Xorshift() >> 8) / 8388607.0f; // [0,1]`、line 304 `v.rate = 1.0f + (u * 2.0f - 1.0f) * pitchJitter_;`。算术验证：`(2^32-1)>>8 = 16777215`（24 位），除以 8388607（2^23-1）得 u∈[0,2.0]；于是 (2u-1)∈[-1,3]，jitter=0.02 时 rate∈[0.980,1.060]；编辑器滑杆上限 0.1（EditorAppChrome.cpp:684）时 rate 可到 1.30（≈+4.5 半音）。头文件 AudioEngine.h:94 承诺「随机 ±range」。测试只断言可关可异（engine_tests.cpp:6187 differ），未覆盖界。
